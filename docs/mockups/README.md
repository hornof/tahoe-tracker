# Mockups

The approved layout is the clickable mockup on the Claude Design canvas: https://claude.ai/artifact/48pVZCLC6X9PQEdoVRSQza#play-Live (private to Luke until shared).

- **Home:** one live cam per resort, each with its snow numbers and 5-day forecast.
- **Resort view:** click a cam to see all of that resort's cams, one big and the rest as tiles; click a tile to make it big.
- **Tabs:** switch resorts or go back home.

Grey boxes stand in for live video; numbers are samples. Details are still to refine during the build.
